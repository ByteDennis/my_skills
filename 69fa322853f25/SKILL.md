## 核心思想

给位置 $m$ 的查询向量乘旋转矩阵 $R_m$，位置 $n$ 的键向量乘 $R_n$，则内积天然只依赖相对距离：

$$q_m^\top k_n = f(m - n)$$

相对位置关系直接编进几何结构，无需模型从数据中归纳。

## 旋转公式

```python
# 对二维子空间旋转（每对维度独立旋转）
theta = pos / (10000 ** (2i / d))   # 不同维度对应不同频率
q_rot = [q * cos(theta) - q_perp * sin(theta),
         q * sin(theta) + q_perp * cos(theta)]
```

## vs Time-bucket

| 维度 | Time-bucket | RoPE |
|------|-------------|------|
| 精度 | 桶内时刻等价，跨桶不连续 | 连续，23:59 与 00:01 天然邻近 |
| OOV | 训练外时间戳直接失效 | 旋转角度可任意外推 |
| 相对关系 | 模型自行学习，浪费容量 | 内积直接编码时间差 |
| 多粒度周期 | 需手工设计日/周/月多级桶 | 不同维度频率自动覆盖秒→小时→天 |

## 用于时间戳

```python
# 将 Unix 时间戳直接作为"位置"传入
t = timestamp / scale   # 归一化到合适范围
rope_embed(x, pos=t)    # 无需分桶，连续可外推
```

- 多频率维度同时捕获秒级、分钟级、小时级周期性
- Attention score 中自带"时间差"先验，便于学习"N小时前"的关系

## 旋转 vs Hash

旋转是周期性的，但不是 hash——区别在于**多频率组合**和**内积的距离结构**：

| | Hash (`pos % N`) | RoPE |
|--|------------------|------|
| 映射 | 多对一，pos=0 与 pos=N 完全相同 | 多频率组合，实用范围内不碰撞 |
| 距离结构 | 无（只有相同/不同） | 内积随距离平滑衰减 |
| 类比 | 只看秒针 | 秒针+分针+时针组合唯一定位时刻 |

内积展开为多频余弦之和，天然随距离衰减：

$$q_m^\top k_n = \sum_i \cos\!\left(\theta_i\,(m - n)\right)$$

低频维度周期极长（$\theta_{\min} \approx 1/10000$），高频维度提供精细分辨率——组合周期远超实际序列长度。

## 局限

- 原始 RoPE 针对整数位置设计，用于非均匀时间戳需归一化或改造频率基
- 超长时间跨度外推时旋转角度过大，需配合 YaRN / NTK 缩放
