# Concept Bottleneck Models — 论文速读
> Koh et al., ICML 2020 <br>
> "Concept Bottleneck Models"

## 问题背景

| 维度 | 说明 |
|------|-----------------|
| 需求 | 放射科医生等领域专家需要用高层概念（"关节间隙变窄"、"骨刺"）与模型交互 |
| 端到端瓶颈 | 黑箱模型 x→y 无法支持概念级查询或干预 |
| 解释性缺陷 | 事后解释法（TCAV / NetDissect）依赖模型碰巧学到概念，且不支持干预 |
| 目标 | 在保持精度竞争力的同时，让模型支持概念查询与**测试时干预** |

---

## 核心洞察

> 在输入 x 与输出 y 之间插入**概念瓶颈层** c，强迫预测路径经过人类可理解的中间概念。

- 训练时需 `(x, c, y)` 三元标注；测试时模型自动预测 `ĉ`，无需人工提供概念
- 支持**测试时干预**：修改 `ĉ` 直接影响 `ŷ`，可获反事实解释（"若模型认为关节间隙不窄，则不会预测重度关节炎"）
- **概念准确率**（concept accuracy）是干预有效性的指示器：概念准确率低 → 干预结果不可信

---

## 模型结构

```
x ──→  g(·)  ──→  ĉ  ──→  f(·)  ──→  ŷ
      (x → c)           (c → y)
```

- `g : Rᵈ → Rᵏ`：将输入映射到 k 个概念预测值（如骨刺概率）
- `f : Rᵏ → R`：仅用概念预测目标（如关节炎严重程度）
- 实现：把端到端网络某层改为 **k 个神经元** + 概念损失约束

---

## 训练变体

| 变体 | 训练方式 | 特点 |
|------|----------|----------|
| **Independent** | f 在真实 c 上训练；g 单独优化 x→c | 训练解耦，测试时 f 接收 ĝ(x) |
| **Sequential** | 先训 g，再用 ĝ(x) 训 f | 分布对齐更好 |
| **Joint** | 联合最小化 `L_Y + λ Σ L_Cj` | λ 控制任务与概念损失的权衡 |
| **Standard** | 忽略概念，仅优化 `L_Y` | 等价于 λ→0，无瓶颈约束 |

> Sequential ≈ λ→∞；Standard ≈ λ→0

---

## 数学目标

**Independent** — g 与 f 分别独立优化：

$$\hat{g} = \arg\min_g \sum_{i,j} L_{C_j}\!\left(g_j(x^{(i)}),\, c_j^{(i)}\right)$$

$$\hat{f} = \arg\min_f \sum_{i} L_Y\!\left(f\!\left(c^{(i)}\right),\, y^{(i)}\right)$$

**Sequential** — 先训 $\hat{g}$（同上），再用预测概念训 f：

$$\hat{f} = \arg\min_f \sum_{i} L_Y\!\left(f\!\left(\hat{g}(x^{(i)})\right),\, y^{(i)}\right)$$

**Joint** — 端到端联合优化，$\lambda$ 权衡两项损失：

$$\hat{f}, \hat{g} = \arg\min_{f,g} \sum_{i} \left[ L_Y\!\left(f(g(x^{(i)})),\, y^{(i)}\right) + \lambda \sum_{j} L_{C_j}\!\left(g_j(x^{(i)}),\, c_j^{(i)}\right) \right]$$

## 实验结论

### ✅ 有效之处

| 发现 | 说明 |
|------|-----------|
| 精度竞争力 | 瓶颈模型任务精度与端到端模型相当甚至更高 |
| 干预提升精度 | 测试时部分修正概念错误，精度显著超越标准模型 |
| 概念准确率高 | CBM 概念准确率远高于从黑箱模型事后提取的结果 |
| 协变量鲁棒性 | 学到正确概念的瓶颈模型对分布偏移更鲁棒 |

### ❌ 局限与注意

| 局限 | 说明 |
|------|-----------|
| 需要概念标注 | 训练时必须有 `(x, c, y)` 三元组，标注成本高 |
| 概念集不完备 | 若 c 不完整，瓶颈可能学到虚假相关而非因果路径 |
| 干预 ≠ 因果干预 | 干预的是模型内部的 `ĉ`，不是现实中的概念 c；c 不需要因果地导致 y |
| 概念准确率的局限 | 验证集可能存在偏差，使虚假相关模型也能取得高概念准确率 |
